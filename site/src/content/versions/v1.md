The first prototype. Sensor breakout boards wired to an ESP32 Feather on a breadboard. Sensor data went over Wi-Fi to Max on a computer.

V2 moved the circuit onto a PCB, to build several nodes for TEI '25. The distance sensor changed from the VL53L4CX to the VL53L1X.
