Pure Data runs on the board: sensing, mapping and synthesis in one patch, without a computer. Sound comes from the speaker on the board. Nodes connect directly over ESP-NOW, without a router.

Work in progress. Two ways to run Pure Data on the board are being compared:

| | espd | ESPdLib |
|---|---|---|
| Framework | ESP-IDF | Arduino |
| Install | Prebuilt firmware, browser flasher (espd-kits) | Arduino library |
| Patch upload | USB or Wi-Fi, live reload | Serial |
| Sensors and GPIO from a patch | Built-in objects (`[i2c]`, `espd/ain`, `espd/din`) | Through Arduino code |
| Network from a patch | Wi-Fi, ESP-NOW | Through Arduino code |

The V3 files move into this repository once the choice is made.
